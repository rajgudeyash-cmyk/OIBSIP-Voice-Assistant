# OIBSIP-Voice-Assistant

Python Internship Task 1 – Voice Assistant

Project Description

A simple voice assistant developed using Python and Flask. It accepts voice commands through a web browser and responds using speech.

Features

- Greeting responses
- Current time
- Current date
- Basic question responses
- Voice output

Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Web Speech API

How to Run

1. Install Python.
2. Install Flask: "pip install Flask"
3. Run: "python app.py"
4. Open "http://127.0.0.1:5000" in Chrome.
